# whisper-uk

Мінімальний голосовий ввід українською для Windows: тиснеш хоткей → говориш →
текст автоматично зʼявляється в курсорі у будь-якому застосунку (браузер, VS Code,
термінал, месенджер).

Власна легка альтернатива Whispering: **без вікон, лише іконка в треї, ~10–15 МБ ОЗУ**.
Транскрипція — у хмарі через **Groq Cloud**, модель `whisper-large-v3`.

```
[хоткей] → 🎙️ запис → ☁️ Groq whisper-large-v3 → 📋 буфер → ⌨️ Ctrl+V у курсор
```

---

## Чому саме так (обґрунтування рішень)

### Чому не Whispering / Tauri / Electron
Whispering — хороший застосунок, але він на **Tauri/WebView2**: заради вікна налаштувань
тягне цілий рушій Chromium і їсть **300–500 МБ ОЗУ**. Нам вікно не потрібне взагалі —
лише іконка в треї. Тому тут **нативний Rust без вебвʼю**: один `.exe` ~2 МБ,
у памʼяті ~10–15 МБ. Це головна причина писати своє.

### Чому Rust, а не Python
- **ОЗУ:** Rust ~10–15 МБ проти ~50 МБ у Python.
- **Запуск:** один самодостатній `.exe` — дабл-клік, сидить у треї. Жодного
  рантайму, інтерпретатора чи PyInstaller.
- Мінус (код складніше правити новачку) для цього проєкту не критичний — логіка проста
  й розбита на маленькі модулі.

### Чому тільки хмара (Groq), без офлайну
Це свідомий вибір для v1:
- **Простота й розмір.** Офлайн-розпізнавання (whisper.cpp) тягне модель на 1–3 ГБ і
  важку обробку на CPU/GPU. Хмара лишає застосунок крихітним.
- **Швидкість.** Groq розпізнає **в десятки разів швидше за реальний час** —
  для коротких реплік затримка ~частки секунди. Локально на CPU велика модель повільна.
- **Точність для української.** `whisper-large-v3` у хмарі дає кращі відмінки/закінчення,
  ніж маленькі моделі, які реально влізли б у швидкий локальний інференс.
- **Вартість.** Groq має безкоштовний tier без картки, якого для особистого диктування
  з головою (див. нижче).

> Офлайн-режим можна додати згодом окремим backend-ом — архітектура це передбачає
> (модуль `groq.rs` ізольований). Але за замовчуванням лишаємо хмару заради легкості.

### Чому `whisper-large-v3`, а не `turbo`
`large-v3` точніший для української (відмінки, рідковживані слова). `turbo` швидший,
але на не-англійських мовах інколи трохи менш точний. Для коротких реплік різниця в
швидкості майже непомітна. Хочеш швидше — зміни `model` у конфігу на
`whisper-large-v3-turbo`.

### Чому мова вказана явно (`uk`), а не Auto
Явне вказання мови помітно підвищує точність — модель не «гадає» між схожими мовами
й не зривається в російську/польську. Якщо часто міксуєш українську з англійськими
термінами — постав `"language": ""` (порожньо = автовизначення) і потестуй.

## Як отримати безкоштовний ключ Groq

1. Відкрий **<https://console.groq.com/keys>** і залогінься (email або Google —
   безкоштовно, картка не потрібна). *Цю сторінку також відкриває пункт меню трея
   «Як отримати ключ Groq…».*
2. Натисни **Create API Key**, дай назву (напр. `whisper-uk`).
3. Скопіюй ключ виду `gsk_...` — **він показується лише один раз**, збережи одразу.
4. Встав його у `config.json` (див. нижче) у поле `groq_api_key`.

**Безкоштовні ліміти Whisper на Groq (станом на 2026):** кілька тисяч секунд аудіо/хв і
~2000 запитів/добу — для особистого диктування цього з головою. Якщо колись упрешся в
ліміт (`429`), зачекай до скидання (північ UTC) або додай картку для Developer tier.

## Встановлення та запуск

### Варіант А. Завантажити готовий `.exe` (найпростіше)
Зайди в **[Releases](../../releases)** цього репозиторію → завантаж `whisper-uk.exe`
з останнього релізу → запусти. Нічого встановлювати не треба, ключ у файл не зашитий.

### Варіант Б. Зібрати самому (потрібен Rust)
```powershell
cargo build --release
```
Готовий файл: `target\release\whisper-uk.exe`. Просто запусти його — зʼявиться іконка
в треї. Перший запуск створює `config.json` (шлях нижче) — впиши туди ключ і в меню трея
обери **«Перезавантажити конфіг»**.

### Автозапуск разом із Windows
Найнадійніше — **вбудований перемикач**: у меню трея постав галочку
**«Запускати з Windows»**. Він прописує запис у реєстр
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, що вказує на поточний `.exe`.
Зняти галочку — вимкнути.

> Чому не папка `shell:startup`: ярлик там легко ламається (якщо перемістити/перейменувати
> `.exe`), і деякі системи його ігнорують. Запис у реєстрі надійніший.
>
> ⚠️ Якщо після ввімкнення автозапуску ти **переміщуєш** `whisper-uk.exe` в іншу теку —
> зніми й знову постав галочку, щоб оновити шлях. Тому тримай exe в постійному місці
> (напр. `C:\Tools\whisper-uk\`).

## Налаштування (`config.json`)

Файл лежить у **`%APPDATA%\whisper-uk\config.json`** (повний шлях:
`C:\Users\<ти>\AppData\Roaming\whisper-uk\config.json`). Відкрити можна прямо з меню
трея → **«Відкрити config.json»**.

```json
{
  "groq_api_key": "gsk_ВСТАВ_СВІЙ_КЛЮЧ",
  "model": "whisper-large-v3",
  "language": "uk",
  "hotkey": "Ctrl+Alt+Space",
  "mode": "toggle",
  "auto_paste": true
}
```

| Поле | Призначення |
|------|-------------|
| `groq_api_key` | Твій ключ `gsk_...` з console.groq.com |
| `model` | `whisper-large-v3` (точніше) або `whisper-large-v3-turbo` (швидше) |
| `language` | `uk` для української; `""` = автовизначення |
| `hotkey` | Глобальний хоткей, напр. `Ctrl+Alt+Space`, `Ctrl+Shift+D`, `F9` |
| `mode` | `toggle` (натиснув/натиснув) або `push_to_talk` (тримаєш) |
| `auto_paste` | `true` — вставляти в курсор; `false` — лише копіювати в буфер |

Після зміни файлу обери в треї **«Перезавантажити конфіг»** (для зміни режиму є ще
швидкі перемикачі в меню).

## Як користуватися

1. Постав курсор у будь-яке текстове поле.
2. Натисни хоткей:
   - **toggle:** натиснув — почав запис (🔴), натиснув ще — зупинив;
   - **push-to-talk:** тримаєш — пише, відпустив — зупинив.
3. Через ~частку секунди текст сам зʼявиться в курсорі.

**Кольори іконки в треї:** сіра — очікує · червона — запис · жовта — розпізнавання ·
фіолетова — помилка (наведи курсор — у підказці буде причина).

### Меню трея

- **▶ Натисни / Тримай: `<хоткей>`** — підказка вгорі меню: показує поточний хоткей і
  що з ним робити (дієслово залежить від режиму).
- **Хоткей ▸** — підменю з готовими комбінаціями (`Ctrl+Alt+Space`, `Ctrl+Shift+Space`,
  `Ctrl+Shift+D`, `Alt+Backquote`, `F9`, `F8`). Вибір застосовується **миттєво**, без
  перезапуску. Свою комбінацію (будь-яку) можна вписати в `config.json`.
- **Режим: Toggle / Push-to-talk** — швидке перемикання режиму хоткея.
- **📊 Статистика** — лічильник: усього запитів до Groq · розпізнаних слів · запитів за
  сьогодні (UTC-доба, як і ліміти Groq). «Відкрити статистику» показує повний
  `stats.json` (успіхи/помилки, символи, секунди аудіо).

> Якщо обраний хоткей зайнятий іншою програмою — застосунок не впаде, лише не
> зареєструє його; обери інший у підменю «Хоткей».
