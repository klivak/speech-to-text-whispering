# Якщо щось не працює

Наведи курсор на іконку в треї — у підказці видно поточний стан і причину помилки
(фіолетова іконка = помилка).

| Симптом | Причина / рішення |
|---------|-------------------|
| **Іконка одразу фіолетова, нічого не пише** | Не вписаний `groq_api_key` у `config.json`. Встав ключ `gsk_...` і обери в треї «Перезавантажити конфіг». |
| **Текст не вставляється, лише в буфері** | Перевір, що `auto_paste: true`. Деякі застосунки блокують емуляцію `Ctrl+V` — встав вручну `Ctrl+V`. |
| **Хоткей не реагує** | Можливо, зайнятий іншою програмою. Зміни `hotkey` у `config.json` (напр. на `F9` чи `Ctrl+Shift+D`) і перезавантаж конфіг. |
| **`Groq повернув 401`** | Невалідний/відкликаний ключ. Створи новий на console.groq.com. |
| **`Groq повернув 429`** | Вичерпано денний ліміт безкоштовного tier. Зачекай до скидання (північ UTC) або додай картку (Developer tier). |
| **`Не знайдено мікрофон`** | Немає активного пристрою вводу або немає доступу. Перевір налаштування звуку Windows і дозвіл на мікрофон. |
| **Розпізнає не ту мову / мішанину** | Постав `"language": "uk"` явно (не порожньо). |
| **Іконка зникла після запуску** | Запусти ще раз; переконайся, що процес `whisper-uk.exe` живий у диспетчері задач. |

## Логи

У debug-збірці (`cargo run`) повідомлення йдуть у консоль. Release-збірка
(`whisper-uk.exe`) працює без консолі — орієнтуйся на колір іконки й tooltip.
Щоб побачити логи, запусти release-білд з консолі:
```powershell
.\target\release\whisper-uk.exe
```
