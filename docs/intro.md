# Whispering + Groq: голосовий ввід українською зі вставкою в курсор

Налаштування безкоштовного (майже) голосового вводу: тиснеш хоткей → говориш
українською → текст автоматично вставляється туди, де стоїть курсор, у будь-якому
застосунку (браузер, VS Code, термінал, месенджер).

- **Додаток:** Whispering (опенсорс, частина проєкту Epicenter, репо `EpicenterHQ/epicenter`)
- **Транскрипція:** Groq Cloud, модель `whisper-large-v3`
- **Платформа:** Windows (так само працює на macOS/Linux)
- **Вартість:** додаток безкоштовний; Groq має безкоштовний tier без картки

> Не плутати: **Whispering** ≠ Wispr Flow (платний) ≠ WhisperWriter (інший застосунок,
> згаданий у розділі «Офлайн-альтернатива»).

---

## Крок 0. Що знадобиться

- Windows 10/11.
- Акаунт Groq (email або Google) — безкоштовно, картка не потрібна.
- (Опційно, але бажано) FFmpeg — для стиснення аудіо перед відправкою, що пришвидшує
  хмарну транскрипцію.

---

## Крок 1. Встановити Whispering

1. Зайди в релізи проєкту на GitHub (`EpicenterHQ/epicenter`, розділ Releases) або на
   сайт epicenter.so → Download.
2. Для Windows завантаж інсталятор: `Whispering_<версія>_x64-setup.exe`
   (альтернатива — `.msi`).
3. Встанови та запусти. Whispering сидить у треї й працює в фоні.

> Whispering — це Tauri-застосунок (легкий, ~10–20 МБ інсталятор), не Electron-монстр.

---

## Крок 2. Отримати безкоштовний API-ключ Groq

1. Відкрий `console.groq.com`, залогінься.
2. Зліва → **API Keys** → **Create API Key**.
3. Дай назву (напр. `whispering`), скопіюй ключ (`gsk_...`) — він показується **один раз**,
   збережи одразу.

**Ліміти безкоштовного tier для Whisper (станом на 2026):**
- `whisper-large-v3-turbo`: ~7200 секунд аудіо/хв, ~2000 запитів/добу.
- Швидкість Groq — десятки разів швидше за реальний час, для диктовки затримка ~частки
  секунди.
- Картка не потрібна. Якщо колись упрешся в ліміт — додаєш картку й отримуєш Developer tier
  (×10 ліміти), але для особистого диктування безкоштовного з головою.

---

## Крок 3. Підключити Groq у Whispering

1. У Whispering відкрий **Settings → Transcription**.
2. **Transcription Service / Provider** → обери **Groq**.
3. У поле **Groq API Key** встав свій `gsk_...`.
4. **Model** → обери **`whisper-large-v3`**.

**Чому саме `whisper-large-v3`, а не `turbo`:**
- `large-v3` — найточніший для української (відмінки, закінчення, рідковживані слова).
- `turbo` швидший, але на не-англійських мовах інколи трохи менш точний.
- Порада: почни з `large-v3`. Якщо швидкість критична й точність влаштовує — перемкнешся
  на `turbo`. Різниця в швидкості для коротких реплік майже непомітна.

---

## Крок 4. Виставити українську мову

1. У тих самих налаштуваннях транскрипції знайди **Language / Output Language**.
2. Постав **Ukrainian (uk)** замість Auto.

> Чому не Auto: явне вказання мови помітно підвищує точність — модель не «гадає» між
> мовами й не зривається в російську/польську на схожих словах. Якщо часто змішуєш
> українську з англійськими термінами (назви бібліотек, команди) — можеш лишити Auto
> й потестити, що краще заходить саме під твій стиль мовлення.

---

## Крок 5. Головне — вставка в курсор

Це те, заради чого все робиться. У **Settings** знайди поведінку після транскрипції
(зазвичай блок **Recording / Output** або **After transcription**):

1. Увімкни **Copy to clipboard** (копіювати результат у буфер).
2. Увімкни **Paste at cursor** / **Auto-paste** (автоматично вставляти в активне поле).

Після цього сценарій такий: ставиш курсор у будь-яке поле → тиснеш хоткей → говориш →
відпускаєш → текст сам зʼявляється в курсорі. Нічого вручну не вставляєш.

> На Windows для надійної роботи глобального хоткея (щоб працював, навіть коли Whispering
> не у фокусі) перемкни **Settings → Recording → Recording backend** на **Native (Rust)**.
> Це лагодить стару проблему, коли шорткат спрацьовував лише у відкритому вікні застосунку.

---

## Крок 6. Налаштувати хоткей

1. **Settings → Shortcuts** (або розділ Recording).
2. Признач **глобальний** хоткей старту/стопу запису — наприклад `Ctrl+Alt+Space`
   або щось, що не конфліктує з твоїми IDE-біндами.
3. Є два режими:
   - **Push / toggle:** тиснеш — почав, тиснеш ще — зупинив.
   - **Voice-activated (hands-free):** натиснув один раз, говориш, воно само стартує/
     зупиняється по паузах. Зручно, коли руки зайняті.

---

## Крок 7. (Опційно) FFmpeg для швидкості

Whispering може стискати аудіо локально перед відправкою в Groq — менший файл, швидша
відповідь.

1. Встанови FFmpeg (напр. через `winget install Gyan.FFmpeg` або скачай білд і додай у PATH).
2. У Whispering → **Settings → Transcription** увімкни **Compress before transcription**.
3. Якщо Whispering не бачить FFmpeg одразу — у свіжих версіях детект на Windows
   полагоджено, перезапуск ПК зазвичай не потрібен.

---

## Крок 8. (Опційно, потужна фіча) AI-постобробка

Whispering вміє після транскрипції прогнати текст через LLM — «причесати» граматику,
прибрати слова-паразити, відформатувати в список тощо.

- **Settings → Transformations** → створи трансформацію з власним промптом і моделлю.
- Можеш зчепити ланцюжок: `Голос → транскрипція (Groq) → виправлення граматики → формат`.
- Моделі підключаються своїми ключами (Groq/OpenAI/OpenRouter/Anthropic тощо). На Groq є
  безкоштовні LLM (напр. Llama 3.3 70B), тож постобробку теж можна тримати безкоштовною.

Для старту цей крок не потрібен — вмикай, коли захочеш «диктувати чернетку, отримувати
чистовик».

## Швидкий чекліст

- [ ] Встановив Whispering (Windows `.exe`)
- [ ] Створив безкоштовний ключ Groq (`gsk_...`)
- [ ] Provider = Groq, Model = `whisper-large-v3`
- [ ] Language = Ukrainian (uk)
- [ ] Copy to clipboard + Paste at cursor = ON
- [ ] Recording backend = Native (Rust)
- [ ] Призначив глобальний хоткей
- [ ] (Опц.) FFmpeg + Compress before transcription
- [ ] (Опц.) AI-трансформація для автоформату

## Офлайн-альтернатива (повністю локально, без хмар і ключів)

Якщо захочеш приватність / нуль залежності від інтернету — два шляхи:

**Варіант А. Той самий Whispering, але локальний рушій.**
- **Settings → Transcription → Service** → обери **Whisper C++** (або **Parakeet**).
- Завантаж модель через кнопку Download. Для української бери **велику Whisper-модель**
  (`large-v3`) — маленькі (Tiny/Small) українську тягнуть слабко.
- Усе інше (вставка в курсор, хоткей) — ідентично хмарному варіанту.
- Мінус: на CPU велика модель повільна; комфортно — з GPU-прискоренням.

**Варіант Б. WhisperWriter (окремий застосунок).**
- Невеликий застосунок: хоткей (за замовч. `Ctrl+Alt+Space`) → запис → автовставка
  в активне вікно.
- Працює локально через `faster-whisper` (або через API, на вибір). Бери модель
  `large-v3` / `large-v3-turbo` для української.

---

## Якщо щось не працює

- **Текст не вставляється, лише копіюється в буфер** → перевір, що ввімкнено
  *Paste at cursor*; на Windows перемкни backend на *Native*.
- **Хоткей не реагує поза вікном Whispering** → backend *Native (Rust)*; перевір, що
  хоткей не зайнятий іншою програмою.
- **Розпізнає не ту мову / мішанину** → вистав Language = Ukrainian явно (не Auto).
- **429 / rate limit від Groq** → вичерпав денний ліміт безкоштовного tier; зачекай до
  скидання (північ UTC) або додай картку для Developer tier.
- **Groq не бачить обрану модель** → у списку обери актуальну (`whisper-large-v3` чи
  `whisper-large-v3-turbo`); застарілі назви прибирали в оновленнях.
